ASSIGNMENT 2
🛒 Simple Shopping Cart 

A beginner-friendly Python shopping cart program that takes customer and product information, calculates the subtotal, applies a discount based on the total amount, and displays a final shopping summary.

✨ Features

- Customer name input
- Input for 3 products and their prices
- Automatic subtotal calculation
- Discount calculation:
  - 5000+ → 20%
  - 3000+ → 10%
  - 1000+ → 5%
  - Below 1000 → No discount
- Final total calculation
- Clean summary using Python f-strings

🛠️ Technology

- Python 3
- "input()"
- "if / elif / else"
- Arithmetic operators
- f-strings

▶️ How to Run

Run the Python file in any Python 3 environment:

python shopping_cart.py

Then enter the customer name, 3 product names, and their prices when prompted.

📌 Purpose

This project is created for practicing basic Python concepts such as user input, variables, conditional statements, calculations, and formatted output.
